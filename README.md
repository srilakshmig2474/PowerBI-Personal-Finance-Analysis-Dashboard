# 📊 Personal Finance and Spending Behavior Dashboard

An interactive **Power BI Dashboard** developed to analyze personal finance, spending behavior, savings patterns, and financial planning using **Power BI, Power Query, and DAX**.

---

# 📌 Project Overview

This project analyzes the Indian Personal Finance dataset to understand income, expenses, savings, occupation, city tier, and demographic trends. The dashboard provides meaningful insights that help users improve budgeting and make better financial decisions.

---

# 🎯 Project Objectives

- Analyze income and expense patterns.
- Track savings performance.
- Compare financial behavior across occupations.
- Study city-tier and demographic trends.
- Support better financial planning.
- Generate business insights using Power BI.

---

# 🛠 Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel (CSV)
- Kaggle Dataset

---

# 📂 Dataset Used

**Dataset Name:** Indian Personal Finance and Spending Behavior Dataset

Dataset contains:

- Income
- Total Expenses
- Actual Savings
- Savings Goal
- Age Group
- Occupation
- City Tier
- Disposable Income
- Expense Categories

# 📈 Key Insights

- Income is higher than expenses.
- Professionals earn the highest income.
- Rent is the largest household expense.
- Tier-3 cities have higher disposable income.
- Budgeting improves financial stability.
- Savings goals help achieve better financial planning.
